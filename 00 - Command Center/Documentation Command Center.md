# Documentation Command Center

This note contains the original DataviewJS prototype and design history for the dashboard.

The supported implementation is now the native **Documentation Command Center** plugin. It does not require Dataview or the CSS snippet in this folder.

## Open the native dashboard

1. Enable **Documentation Command Center** in **Settings → Community plugins**.
2. Open the command palette.
3. Select **Documentation Command Center: Open dashboard**.

The prototype source remains in `code/script.js` for comparison while the native view evolves.
